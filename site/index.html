The house standard

Every repo gets graded against this. No surprises.

README

  • Title and a real one-line description
  • Motivation, tech stack, features
  • Installation and how-to-use guides

About box

  • Description filled in
  • Website link set
  • Topics and tags added

License

  • A LICENSE file in the repo root
  • So the badge shows on your repo page

Contribute, Credits and License sections are skipped on purpose. GitHub already renders those natively.
